# Steam Input layouts

The recommended layouts for the Xbox controller and the Steam Deck land here in M5.

The only hard requirement for nwpad: the left stick is set to **Joystick Move** and the right stick to **Joystick Camera**, so both reach the game as gamepad sticks. Deadzones, response curves, and inversion are all tuned here in Steam Input; nwpad uses raw values. Buttons, trackpads, and gyro are free for whatever you like, since nwpad doesn't handle them.
