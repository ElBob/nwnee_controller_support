# Steam Input layouts

nwpad needs both sticks to reach the game as **gamepad joysticks** (Steam Input
"Joystick Move" on each stick). Buttons, triggers, trackpads, and gyro are Steam
Input's job; NWN:EE has no gamepad support of its own, so they're bound to the
game's keys and mouse.

## Xbox: `nwpad_xbox.vdf`

A port of the Steam Deck community layout *Neverwinter Nights Console Port*
(workshop 3095778009), keeping its buttons, with both sticks switched to gamepad
joysticks. Generated by `make_layouts.py`.

| Control | Binding |
|---|---|
| Left stick | gamepad left stick (nwpad: move) |
| Right stick | gamepad right stick (nwpad: camera) |
| Hold LB | right stick becomes the mouse; its click is left click. Also sends `[` (picker: previous bank) |
| LS click (hold) / RS click | Scroll Lock: nwpad's quickbar picker, pick with the right stick / Space (pause) |
| A / B / X / Y | C character sheet / B spellbook / R rest / I inventory |
| D-pad | ↑↓ zoom, → journal (J), ← map (M) |
| LT / RT | right click (radial menu) / left click |
| RB | `]` (picker: next bank) |
| View / Menu | Esc / G |

### Installing it (until it's published as a community layout)

With Steam **closed**:

1. Copy `nwpad_xbox.vdf` to
   `~/.local/share/Steam/steamapps/common/Steam Controller Configs/<your id>/config/704450/controller_xboxone.vdf`.
2. In the same `config` directory, add to `configset_controller_xboxone.vdf`:
   ```
   "704450"
   {
       "autosave"		"1"
   }
   ```
3. Make sure Steam Input is on for NWN:EE (Properties → Controller → "Enable Steam Input"; in
   `localconfig.vdf` this is `apps/704450/UseSteamControllerConfig = 2`).

Steam's controller log (`~/.local/share/Steam/logs/controller.txt`) shows
`Loaded Config for Local Selection Path for App ID 704450 ... controller_xboxone.vdf`
when it's in use.

## Steam Deck: `deck_from_console_port.py`

Converts your own copy of *Neverwinter Nights Console Port* for nwpad, in place,
with a backup (run it with Steam closed):

```
steam-input/deck_from_console_port.py \
  "~/.local/share/Steam/steamapps/common/Steam Controller Configs/<your id>/config/704450/controller_neptune.vdf"
```

- Left stick: from the camera arrow keys to a gamepad joystick (nwpad movement),
  keeping its click binding.
- Right stick: from the companion-command radial menu to a gamepad joystick
  (nwpad camera). The companion menu currently has no other home.
- Trackpads, triggers, buttons, back grips, and the quickbar radial are unchanged.

The workshop layout itself isn't part of this repository.
